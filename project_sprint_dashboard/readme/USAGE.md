Go to Project > Reporting > Sprint Dashboard, or click on the **Sprints**
button of a project.

- Select the customer and navigate between sprints with the arrows.
- Click on an indicator, a project or a segment of a bar to open the
  corresponding tasks.
- Click on a sprint in the history to display it.

Run tasks:

- A run task planned in a sprint follows the normal flow.
- A run task without sprint is put, once done, in the sprint of its closing
  date. Open run tasks without sprint are not shown.
- The **Run** banner shows the number of run tickets, their time and the share
  of the sprint time taken by run. Click on it to open the run tickets.
- A **run** badge is shown on the projects with run tickets.
- In the last sprints, the done bar is split between planned work and run.

In the task list, the `Sprint Status` column, the **Run** / **Planned Work**
filters and the groupings are also available.
