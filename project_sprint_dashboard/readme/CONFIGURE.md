- Set a task state on every stage (`project_task_stage_state`): the dashboard
  relies on the task state, not on the stage.
- Enable sprints on the projects and set their customer.
- On each project using sprints, set the **Run Tags** (e.g. bug, urgent): tasks
  with one of these tags are run work.
- Generate the sprints from the yearly sprint (Project > Configuration > Sprint).
